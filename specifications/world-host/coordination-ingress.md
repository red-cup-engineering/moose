# Original World gateway contract

The reusable gateway now belongs to MOOSE. Its current ownership, requirement
trace, unchanged wire contract and receiving obligations are specified in
[Dimension and World coordination](../dimension-world-coordination.md).

The relocated source retains its original reference to this path. The original
host-specific coordination contract remains with
[FeltOS at the source revision](https://github.com/red-cup-engineering/feltos/blob/cae43a25f2134235ab2f2f92c96374760d71074d/specifications/world-host/coordination-ingress.md).
FeltOS continues to own host placement, local state and lifecycle. MetroPlat
continues to own its account/session/office recognition and Work semantics.
ActivityPub and the native actor-request provider continue to own signed
transport and request/reply custody.
